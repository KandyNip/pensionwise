# 通脹如何吃掉你的退休金：2026年最被忽視的退休殺手

講真，大多數人規劃退休的時候，只關心兩件事：每月要存幾多錢，和MPF回報有幾高。但有一個東西，不聲不響地把你的努力吞掉一大半——通脹。

你可能覺得2%的通脹率不算什麼，一年漲2%而已嘛。但20年、30年下來，這個數字會把你的退休金購買力砍掉一半以上。

這篇文章用香港和台灣的真實數據，幫你搞清楚通脹到底怎麼影響你的退休生活，以及你可以做什麼來保護自己的錢。

## 通脹到底在做什麼？

簡單講：**通脹讓你的錢越來越不值錢。**

今天你用HK$100塊可以買到的東西，明年可能要HK$102塊。聽起來沒什麼，但如果每年都是這個速度：

| 時間 | HK$100 的實際購買力 |
|------|-------------------|
| 現在 | HK$100 |
| 10年後 | 約 HK$82 |
| 20年後 | 約 HK$67 |
| 30年後 | 約 HK$55 |

沒看錯——**30年後，你手裡的100塊，只買得到現在55塊錢的東西。**

這意味著什麼？如果你退休時需要每月HK$20,000的生活費，以2%的年通脹率計算，20年後你需要HK$29,700才能維持同樣的生活水準。不是因為你變奢了，而是所有東西都漲價了。

![通脹侵蝕購買力](/assets/images/inflation-illust-1.jpg)

## 2026年真實通脹數據：比你想的嚴重

### 香港

根據香港政府統計處2026年6月數據，綜合消費物價指數（CPI）按年上升**2.0%**。但這個是整體平均數，跟退休人士實際感受到的漲價幅度不太一樣。

來看看具體分項：

| 項目 | 2026年6月按年變動 |
|------|-----------------|
| 電力、燃氣及水 | +9.2% |
| 交通 | +5.3% |
| 其他服務（含醫療） | +5.2% |
| 雜項物品 | +2.3% |
| 住屋 | +1.1% |
| 外出就餐及外賣 | +0.8% |
| 基本食品 | -0.5% |

注意看：**電力燃氣漲了9.2%、交通漲了5.3%、醫療服務漲了5.2%。** 這些恰恰是退休人士開支最重的項目——你老了之後，出行靠的士、家裡要開冷氣、身體需要看醫生。這些開支的漲幅遠超官方「平均」數字。

渣打銀行預計2026年全年香港通脹率為**2.1%**，較去年的1.4%明顯上升，主要受國際油價上升和中東局勢影響。

### 台灣

台灣的情況更嚴峻。2026年6月CPI按年上升**2.6%**，創17個月新高，連續兩個月突破央行2%警戒線。其中交通通訊漲了4.14%、油價飆升19.45%、外食價格漲了3.02%。

核心CPI（扣除蔬果和能源）也達到2.45%，這才是反映長期趨勢的指標。

![生活開支漲價](/assets/images/inflation-illust-2.jpg)

## 退休人士的「實際通脹率」比官方數字高

這是很多人不知道的：退休人士經歷的通脹，通常比官方CPI高0.5%到1%。

原因很簡單：**你的消費結構跟年輕人不一樣。**

官方CPI是一籃子商品的平均價格，權重是根據全港家庭平均開支結構算出來的。但退休人士花的錢，跟在職人士差很遠：

| 開支項目 | 退休人士佔比 | 一般家庭佔比 | 通脹速度 |
|---------|------------|------------|---------|
| 醫療健康 | 高 | 低 | 快（醫療服務+12.2%） |
| 房屋水電 | 高 | 中 | 快（+9.2%） |
| 交通出行 | 中高 | 中 | 快（+5.3%） |
| 教育培訓 | 無 | 高 | 中（+4.0%） |
| 飲食 | 高 | 中 | 中（+0.8%） |

醫療服務在2026年6月按年漲了12.2%，是整體通脹的6倍。如果你退休後身體狀況不太好、需要經常看醫生做物理治療，你個人感受到的通脹遠不止2%。

經濟學上有個概念叫 **「退休人士通脹指數」**，專門追蹤老年人實際面對的價格變化。多國研究顯示，這個指數通常比官方CPI高出0.5%到1.5%。

## 2%通脹 vs 4%通脹：差1%天差地別

很多人說「2%不高啊，有什麼好擔心的」。來算一筆賬。

假設你現在35歲，計劃65歲退休，退休後需要每月HK$20,000生活費（以今天物價計算），退休後預計活25年。

**如果年通脹率是2%：**
- 退休時每月需要：HK$36,400
- 退休後30年總需要：約HK$1,880萬
- 65歲時需要準備的總退休金：約HK$920萬

**如果年通脹率是4%：**
- 退休時每月需要：HK$64,900
- 退休後30年總需要：約HK$3,540萬
- 65歲時需要準備的總退休金：約HK$1,580萬

**通脹率差2個百分點，需要的退休金差了近70%。**

這就是為什麼通脹假設這麼關鍵。你退休計劃裡面用的通脹數字，直接決定了你要存多少錢。

## MPF能跑贏通脹嗎？

回到香港最多人供的MPF。看看各類基金過去的回報：

| MPF基金類別 | 過去12個月回報 | 2026年通脹率 | 實質回報 |
|------------|--------------|------------|---------|
| 股票基金 | +19.6% | 2.0% | +17.3% |
| 混合資產基金 | +8.5% | 2.0% | +6.4% |
| 債券基金 | +3.2% | 2.0% | +1.2% |
| 保守基金/貨幣市場 | +1.8% | 2.0% | **-0.2%** |

看到了嗎？**如果你把MPF放在保守基金或貨幣市場基金，你的實質回報是負數。** 你的錢在名義上沒有虧，但購買力正在一點一滴地被通脹偷走。

這就是為什麼我一直強調——MPF一定要投資，不要放在保守基金裡「保值」。保守基金的「保守」，其實是最危險的選擇，因為它給你一個安全的錯覺，同時悄悄虧掉你的購買力。

## 對抗退休通脹的四個實用策略

### 1. 確保你的投資組合有足夠股票比重

長期來看，股票是唯一能持續跑贏通脹的資產類別。全球股市過去100年的年化實質回報約4-5%。這不是說每年都賺，而是長期平均。

如果你還有20年以上才退休，你的退休投資組合裡至少應該有50-60%在股票或股票基金。MPF的DIS預設投資策略也是這個邏輯——年輕時多配股票，臨近退休才逐步減倉。

### 2. 留意通脹掛鉤債券（iBonds等）

香港政府從2011年起發行通脹掛鉤債券（iBonds），回報直接跟本地通脹掛鉤，最低保證回報率通常為2%。雖然回報率不算高，但至少保證了購買力不會被通脹侵蝕。

如果你的退休組合裡面有一部分想要穩健配置，iBonds是一個合理選擇。不過要注意，iBonds有持有年限要求，提前贖回可能影響回報。

### 3. 退休後不要把所有錢放銀行定存

很多人退休後習慣把所有錢放銀行定存，覺得「安全」。但看看2026年的利率環境：

- 香港主要銀行定期存款年利率：約2-3%
- 通脹率：約2%
- 實質回報：**0-1%**（稅前可能還有正回報，但扣除稅費後幾乎為零）

銀行定存不是壞東西，但如果你的退休生活費全靠定存利息，你的購買力正在緩慢縮水。你需要把一部分資金配置在能產生實質正回報的資產上——股票、REITs（房地產信託基金）、或者分紅股票。

### 4. 定期檢視你的退休預算

通脹不是一個固定數字，它每年都在變。2020年全球通脹率不到1%，2022年美國通脹飆到9.1%。中東局勢、能源價格、供應鏈問題，都可能讓通脹突然加速。

建議每年至少檢視一次你的退休預算，根據最新通脹數據調整你的儲蓄目標和投資策略。不要設定了退休計劃就丟在那裡不管——那是最危險的做法。

## 最容易被通脹吃掉購買力的三類人

**第一類：把所有錢放銀行或保守基金的人。** 名義上不虧，實質上每天都在貶值。

**第二類：只靠固定年金或定額退休金生活的人。** 如果年金沒有每年按通脹調整，20年後你能買到的東西只剩現在的六成。

**第三類：沒有提前開始投資的人。** 通脹是每天都在發生的事，你等得越久，你的錢被偷走得越多。早10年開始投資，實質回報差距可以達到一倍。

## 小結

通脹不是什麼抽象的經濟概念，它是實實在在偷你退休生活品質的小偷。

2%的通脹，30年後吃掉你45%的購買力。
3%的通脹，30年後吃掉59%。
4%的通脹，30年後吃掉70%。

你不需要恐慌，但你需要重視。確保你的退休投資有足夠的股票比重，不要把所有錢放定存，定期檢視你的計劃，根據實際通脹調整策略。

**今天就做一件事：登陸你的MPF戶口，看看你的錢到底投在了哪裡。如果超過一半在保守基金，認真考慮轉去股票或混合基金。**

你的退休金，值得跑贏通脹。
