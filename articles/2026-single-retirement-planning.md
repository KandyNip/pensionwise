# 單身退休規劃：一個人也要安心的財務、醫療、社交全面準備

單身不是問題。沒準備才是。

我身邊有個朋友，55歲，女性，從來沒結過婚。她在台北有一間小公寓，工作穩定，看起來什麼都不缺。直到有一天她跟我說：「我最近在想，如果我60歲那天在家摔倒了，誰幫我打119？」

這個問題把我問住了。

我們做退休規劃，看到的都是「夫婦情境」——夫妻兩個人一起算生活費、一起領年金、一起變老。但現實是，越來越多的人不會走這條路線。

根據內政部統計，2025年底台灣15歲以上未婚人口達**701萬人**，其中30歲以上佔**52.2%**。主計總處2025年家庭收支調查更顯示，一人家戶佔比達**17.33%**，史上首次超過四人家戶（16.63%）。一加上兩人戶，總計超過所有家戶的**51.6%**。（[主計總處家庭收支調查](https://www.dgbas.gov.tw/)，[Focus Taiwan報導](https://taiwanwireservice.com/small-households-surpass-half-of-taiwans-total-dgbas/)）

這不是少數人的問題。這是一股需要被正視的趨勢。

單身退休，和夫婦退休，最大的差別是什麼？三個字：**沒人分**。沒人分攤房租、沒人第二份收入、沒人幫你跑腿拿藥、沒人幫你簽手術同意書。

這篇把單身退休的三大缺口——財務、醫療、社交——用港台真實數據拆開來看，然後給出具體的解法。

## 缺口一：財務——沒有人幫你分攤風險

夫婦退休最大的財務優勢是「分攤」。兩個人住同一間房子，租金或房貸是除以二的。水電瓦斯、伙食開銷，很多費用都是共用。

單身不行。所有開銷一人扛。

根據南山人壽引用內政部及主計總處數據：台灣單身人口以每月平均消費**2.66萬元**推估，退休後至少需要**700萬元以上**才能維持基本生活。若以女性平均壽命87.48歲計算，65歲退休還有22年以上要撐。（[工商時報](https://www.unlistedstock.com.tw/news/detail/33389602)）

夫妻的情況呢？65歲後每年支出約63萬元，到87歲至少需要**1,350萬元**。聽起來多很多？但兩個人分，每人其實差不多。差別在於——夫妻有兩份勞保年金、兩份勞退，加起來保障更完整。

單身只有一份。

**勞保年金平均月領多少？** 根據勞保局最新數據，領取老年年金人數超過201萬人，平均月領僅**19,312元**。這點錢，在台北連房租加伙食都很緊。

更殘酷的現實是：國際調查顯示，全球50歲以上民眾中，**42%的退休儲蓄在壽命前十年就用完了**。如果以百歲為目標，**81%的人退休金準備不足**。（[南山人壽分析](https://www.rmim.com.tw/news-detail-44852)）

對單身來說，這個數字只會更嚴峻。

### 單身版退休金怎麼算？

用4%法則做個粗估。假設你65歲退休，每月需要4萬元生活費（一人版，含房租、伙食、醫療、交通）：

- 年支出：48萬元
- 需要的退休金總額：48萬 ÷ 4% = **1,200萬元**

如果你只能依靠勞保年金月領1.9萬，年領約23萬。缺口就是每年25萬。25萬 ÷ 4% = 還需要額外**625萬元**的自備資金。

數字不會騙人。單身退休的財務門檻，確實比夫婦版高。

**解法是什麼？**

1. **提早起步**：複利需要時間。35歲開始每月存1萬，年化5%，到65歲約820萬。45歲才開始，同樣條件只剩約340萬
2. **年金打底**：用年金險或勞保年金覆蓋基本開支的至少30-40%，剩下靠自己投資組合。關於年金險vs自投的比較，可以看：[年金險vs自己投資：退休終身現金流該怎麼選？](/article/2026-annuity-vs-self-investment-retirement-cashflow)
3. **緩衝加碼**：單身版4%法則建議比夫婦版多準備20-30%的緩衝，因為你沒有第二份收入當後盾
4. **善用勞退自提**：每月自提6%勞退，可以減少當年度所得稅，同時讓退休帳戶滾更大

## 缺口二：醫療——沒人幫你簽那張同意書

這是單身退休最容易被忽略、卻最致命的一環。

夫妻有配偶。住院了，配偶簽字。失能了，配偶決定。需要長期照護了，配偶是天然的照顧者。

單身沒有這個安全網。

**台灣：病人自主權利法（2019年實施）**

2019年1月，台灣正式實施《病人自主權利法》，是亞洲第一個保障病人醫療自主權的專法。年滿20歲、具完全行為能力的成年人，可以簽署「預立醫療決定」（AD），提前寫下自己在特定臨床條件下要接受或拒絕哪些醫療處置。

你可以指定的內容包括：
- 心肺復甦術（CPR）
- 人工呼吸器
- 血液製品
- 鼻胃管灌食

這些都寫在AD裡。當你無法表達意願時，醫療團隊必須遵照你的預立決定。

**對單身族來說，AD格外重要。** 因為你沒有配偶替你決定。如果不事先寫好，到了緊急時刻，可能是遠房親戚、甚至是社工來幫你做決定。那未必是你想要的結果。

除了AD，另一個工具是「醫療委任代理人」。你可以指定一位信任的朋友、晚輩或專業人士，在你無法表達時替你做出醫療決定。

**香港：持久授權書（Enduring Power of Attorney）**

香港的法律工具不同。你可以在精神能力健全時簽署「持久授權書」（EPA），指定一位受權人，在你日後精神上無行為能力時，代你處理財務和物業事宜。2026年香港法律改革委員會持續推動簡化EPA程序。

### 長照：單身最不能逃避的課題

台灣已正式進入超高齡社會。截至2026年6月底，65歲以上人口達**476萬1,941人**，佔總人口**20.49%**。台北市更高達**24.61%**。（[內政部戶籍統計](https://www.news.cn/tw/20260710/67d0c64b6a6744da84116d3bc93ce28d/c.html)）

國發會推估更驚人：2045年台灣人口跌破2000萬，2075年降至1215萬，老年人口佔比將達**52.9%**。（[國發會人口推估](http://www.taiwan.cn/taiwan/taiwan/)）

長照3.0於2026年上路，預算約1,103億元，ABC據點超過15,000處。但長照補助有上限——重度失能每月最高給付約36,180元，一般戶自付16%。如果你需要外籍看護，月薪2.5萬到3.5萬元全自費。

**單身的人，誰來管理你的長照？**

沒人幫你盯看護、沒人幫你跟長照中心溝通、沒人在你失智後替你管錢。

解法：
- **安老信託**：把財產交給受託銀行管理，依合約按月撥付長照費用。可以指定信託監察人監督執行
- **預立醫療決定 + 醫療委任代理人**：提前寫好意願，指定你信任的人
- **了解社福資源**：各縣市社會局提供獨居老人服務、緊急救援系統、關懷訪視

## 缺口三：社交——隱形的養老本

財務和醫療是有形的缺口。社交是無形的。

但它的影響可能比你想的更深。

研究反覆證明：社會孤立對健康的傷害，相當於每天抽15根煙。獨居老人的失智風險、憂鬱症發生率、心血管疾病死亡率，都顯著高於有社交網絡的同齡人。

單身退休的人，如果沒有刻意經營社交圈，很容易陷入一個惡性循環：退休 → 失去工作社交 → 朋友越來越少 → 越來越不願出門 → 健康惡化 → 更孤立。

夫婦至少還有家裡那個人。單身的人，需要主動建立自己的「社交基礎建設」。

**台灣：社區照顧據點**

長照3.0的C級巷弄長照站（社區照顧據點），至2024年底已達**5,030處**，遍布全台。這些據點不只是給失能長者用的——很多據點開辦健康促進課程、共餐活動、認知訓練。

對單身退休族來說，這些據點不只是「服務」，更是你每天出門的理由、認識新朋友的場合。

另外，各縣市的「長青學苑」「樂齡學習中心」提供課程，從書法到手機攝影到外語，學費很便宜。

**香港：獨長者社區支援**

香港社署資助多個長者地區中心及長者鄰舍中心，提供獨居長者探訪、電話慰問、社交活動等服務。2026年Q2全港家庭住戶約**279萬戶**，平均人數僅2.6人。（[政府統計處](https://www.censtatd.gov.hk/)）

香港也越來越多「共居」試驗項目，由社企或非牟利機構營運，讓單身長者在私人空間之外，擁有共享的社交環境。

**解法很簡單：**

1. 退休前就開始建立「非工作社交圈」——興趣社團、志工團體、運動社群
2. 退休後固定參加社區活動，把社交排進行事曆
3. 考慮共居或共生社區作為居住選項
4. 保持跟老朋友定期聯繫——約飯、約運動、約旅行

## 香港視角：單身一樣是趨勢

不只是台灣。香港也在走同一條路。

根據政府統計處2026年數據，2025年15歲及以上從未結婚的人口：女性**100萬**、男性**95.9萬**。65歲以上從未結婚的人：女性5.31萬、男性3.72萬——這個數字每年都在增長。（[政府統計處](https://www.censtatd.gov.hk/wbr/B1130303/B11303032026AN26/att/tc/B11303032026AN26.pdf)）

香港的單身退休族面對的挑戰和台灣類似：

- **MPF足夠嗎？** 平均戶口約32萬港元，扣掉5%提領規則，能轉成的年金相當有限
- **綜援是最後防線**：但申請綜援需要資產審查，而且很多人不願走到這一步
- **高齡津貼（生果金）**：70歲以上每月3,140港元（2026年），但僅能覆蓋極小部分生活費

對香港的單身退休族，策略跟台灣一樣的核心邏輯：用年金覆蓋底線、保持投資彈性、提前處理醫療授權、建立社交網絡。

## 單身退休完整Checklist

把上面的內容整理成一張清單。單身退休，你需要準備四件事：

### 財務面
- [ ] 算出你的單身版退休缺口（用[退休缺口計算器](/retirement-gap.html)）
- [ ] 確認勞保/勞退/國民年金月領金額
- [ ] 評估年金險是否適合打底（至少覆蓋基本開支30%）
- [ ] 建立投資組合，保持成長對抗通脹
- [ ] 預留6個月以上緊急預備金
- [ ] 考慮安老信託保障長照資金

### 法律面
- [ ] 簽署預立醫療決定（AD）——台灣適用
- [ ] 指定醫療委任代理人
- [ ] 考慮意定監護或持久授權書（香港適用）
- [ ] 立好遺囑——即使單身也需要
- [ ] 指定保險受益人

### 醫療面
- [ ] 了解健保自付額上限和商業保險覆蓋
- [ ] 確認你所在縣市的長照資源（ABC據點位置）
- [ ] 登記獨居老人服務（如適用）
- [ ] 定期健檢，提早發現問題

### 社交面
- [ ] 退休前建立非工作社交圈
- [ ] 固定參加社區活動
- [ ] 了解共居/共生社區選項
- [ ] 保持與家人、朋友的定期聯繫

## 寫在最後

回到開頭那個朋友的問題：「如果我60歲那天在家摔倒了，誰幫我打119？」

答案是：你可以提前安排好。

緊急救援系統（台灣的1999或各縣市獨居老人緊急救援）、智慧手環跌倒偵測、鄰居互助網絡——這些都是解法。但前提是你得**提前準備**。

單身退休的核心邏輯只有一句話：**所有夫婦之間自然分攤的事，你都要自己安排好。**

收入、醫療決定、長照管理、社交生活——四個面向，每一個都要提前規劃。

好消息是：700萬未婚人口代表你不是少數。越來越多的產品、服務、法律工具，正在為單身退休族量身打造。

壞消息是：時間不等人。越早開始準備，選擇越多。

一個人也要安心。前提是你有準備。
